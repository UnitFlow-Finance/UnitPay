# UnitPay Presentation Materials

This folder contains presentation-ready write-ups for the current UnitPay demo.

- [`unitpay-presentation.md`](unitpay-presentation.md): slide-by-slide deck outline with on-slide bullets and speaker notes.
- [`speaker-script.md`](speaker-script.md): polished continuous video script for a recorded walkthrough or live demo.

The materials now cover the implemented product surface:

- Circle User-Controlled Wallet onboarding, backup completion, and session-aware public links
- Unified Gateway balance, cross-chain deposits, custom RPC-aware chain reads, and chain-specific transfer control
- Payment links with UnitPay wallet payments and external wallet `depositFor` payments into the payee Gateway balance
- Split payments, escrow, UnitPacket, and public/private Escrow Pods
- Pod discovery, deep links, collaborative payment-link funding, and contribution tracking
- Full P2P marketplace with merchant dashboard, on-chain Arc Testnet offer/trade flows, saved payout details, encrypted trade chat, filters, and trade attention indicators
- Virtual cards with clickable detail pages, masked copy controls, status actions, funding/withdrawal controls, and AI-agent-ready card language
- Universal QR generation, QR scanner access, and uploaded QR decoding for address and payment flows
- Rich OpenGraph/Twitter share cards for public UnitPay objects
- Metadata registry/on-chain storage direction for serverless-safe public objects
- Testnet-only guardrails and production-hardening notes

Use the speaker script when recording the demo. Use the deck outline when building slides in a presentation tool.
