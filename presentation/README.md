# UnitPay Presentation Materials

This folder contains presentation-ready write-ups for the UnitPay demo.

- [`unitpay-presentation.md`](unitpay-presentation.md): slide-by-slide deck outline with on-slide bullets and speaker notes.
- [`speaker-script.md`](speaker-script.md): continuous speaking script for a live presentation or recorded demo.

The content is based on the current codebase features:

- Circle User-Controlled Wallet onboarding and session handling
- Gateway unified balance deposit and spend flows
- Payment links with UnitPay wallet and external wallet payment paths
- Split payments
- Escrow
- UnitPacket
- Escrow Pods
- Merchant dashboard
- Arc Testnet Solidity contracts
- Testnet-only guardrails
